# Istruzioni per LLM
# Feature indica il modulo python da importare il quale contiene le fn:
# Gli Scenario sono i nomi delle funzioni di test che dovrai generare
# Given contiene la descrizione dei parametri di input
# When descrive quali fn: del modulo da testare
# Then contiene la descrizione delle asserzioni da svolgere


Feature: ecommerce

  # 0 Punti fedeltà
  Scenario: test_calcola_punti_fedelta_zero_punti_per_dieci_euro_acquisto
    Given un acquisto di 3 euro
    When un cliente conclude un acquisto fn:calcola_punti_fedelta ne calcola i punti fedeltà
    Then il cliente riceve 0 punti fedeltà perchè l'acquisto è inferiore a 10 euro

  # 1 Sconto su prezzo
  Scenario: test_calcolo_prezzo_scontato_sopra_100
    Given un prezzo di 80 e uno sconto di 1000
    When un dipendente applica un sconto fn:calcola_prezzo_scontato gli dai il prezzo scontato
    Then il dipendente riceve l'errore "la percentuale di sconto deve essere tra 0 e 100"

  Scenario: test_calcolo_prezzo_scontato_prezzo_negativo
    Given un prezzo di -80 e uno sconto di 10
    When un dipendente applica un sconto fn:calcola_prezzo_scontato gli dai il prezzo scontato
    Then il dipendente riceve l'errore "il prezzo non può essere negativo"
  
  Scenario: test_applica_codice_sconto_non_trovato
    Given un prezzo di 120, una chiave 10 e un dizionario {1: 10, 2: 15}
    When un dipendente applica un sconto tramite codice fn:applica_codice_sconto gli dai il prezzo scontato
    Then il dipendente riceve il prezzo inalterato per il codice non è presente nel dizionario

  # 3 Calcolo di IVA su prezzo
    Scenario: test_calcola_iva_prezzo_negativo
      Given un prezzo di -50 netto e una aliquota di 20
      When un dipendente calcola un iva fn:calcola_iva gli dai il prezzo con l'incremento dell'iva
      Then il dipendente riceve un errore "il prezzo netto non può essere negativo"

    Scenario: test_calcola_iva_prezzo_negativo
      Given un prezzo di 50 netto e una aliquota di -20
      When un dipendente calcola un iva fn:calcola_iva gli dai il prezzo con l'incremento dell'iva
      Then il dipendente riceve un errore "l'aliquota non può essere negativa"
  
  # 4 Modifiche delle righe del carrello
    Scenario: test_crea_riga_carrello
      Given il nome_prodotto Cola, il prezzo_unitario 0, quantita di 300
      When il cliente aggiunge un riga al carrello fn:calcola_iva gli dai il prezzo con l'incremento dell'iva
      Then il cliente riceve l'errore "il prezzo unitario non può essere negativo"

    Scenario: test_crea_riga_carrello
      Given il nome_prodotto Cola, il prezzo_unitario 10, quantita di -1
      When il cliente aggiunge un riga al carrello fn:calcola_iva gli dai il prezzo con l'incremento dell'iva
      Then il cliente riceve l'errore "la quantità deve essere maggiore di zero"

    Scenario: test_svuota_articoli_esauriti_articoli_presenti
      Given le righe_carrello [{
        "nome": Sushi,
        "prezzo_unitario": 30,
        "quantita": 2,
        "subtotale": round(prezzo_unitario * quantita, 2),
      }] e il dizionario magazzino {Sushi: 5}
      When il dipendente elimina le righe dal carrello i quali non hanno disponibilità in magazzino fn: svuota_articoli_esauriti
      Then ritorna una lista uguale a righe_carrello perchè presente in magazzino

    Scenario: test_svuota_articoli_esauriti_articoli_non_sufficenti
      Given le righe_carrello [{
        "nome": Sushi,
        "prezzo_unitario": 30,
        "quantita": 2,
        "subtotale": round(prezzo_unitario * quantita, 2),
      }] e il dizionario magazzino {Sushi: 0}
      When il dipendente elimina le righe dal carrello i quali non hanno disponibilità in magazzino fn: svuota_articoli_esauriti
      Then ritorna una lista senza il Sushi perchè non presente in magazzino
